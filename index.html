EDA → modeling

What the exploration changed.

01Boundary concentration

Very recent activity motivated recency, 1h / 5h / 12h / 24h / 3d / 7d / 14d / 30d / 60d / 180d windows, velocity ratios and interarrival features.

02Weak raw marginals

Small class differences motivated recent-vs-baseline deviations, interactions and multi-model blending instead of relying on transaction count alone.

03Near-fixed history

≈180-day histories motivated completeness/censoring checks and long-window baselines for 30d/60d/180d comparisons.

04Temporal target drift

Monthly target movement motivated a chronological holdout in addition to frozen signal-level cross-validation.

05Signal-day ambiguity

The timestamp audit produced CUT_A/B/C experiments; the strict pre-date cutoff stayed because it was the safest future-facing interpretation.

03 / Method

Built around the timestamp boundary, not around a leaderboard shortcut.

The signal date contains no event time. We therefore use the strictest unambiguous cutoff: only transactions strictly before 00:00 on the signal date enter the production feature set.

Baseline behavior

Transaction count, active days, amount distribution, direction mix, transaction types and history completeness.

B

Temporal structure

Last-event recency, interarrival gaps, burstiness, short-gap concentration and recent cadence shifts.

C

Signal-level validation

Transactions are never split across folds. One signal produces one feature row and one target.

D

Human-in-the-loop output

The system prioritizes review queues. It does not claim to replace an analyst or provide a calibrated probability.

Final ensemble

Independent learners, common ranking scale.

Each model’s test scores are converted to percentile ranks before weighted averaging, preventing score-scale differences from dominating the blend.

06 / Conclusion

The useful signal was in temporal shape, not a single headline variable.

Our strongest conclusion is methodological: preserve the event boundary, compare behavior to a signal’s own history, and validate as if the next batch arrives in the future.

0117.18% positive

The task is imbalanced, so ranking quality matters more than a naive accuracy threshold.

0295.4% within 60s

Transaction activity concentrates extremely close to the signal boundary.

03Weak single features

The best audited standard univariate feature reached only ~0.542 AUC.

04Strict CUT_A retained

Signal-day rows could not be safely ordered in time and hurt chronological robustness when included.

05Temporal features mattered

Recency, cadence, burstiness and behavior-vs-baseline were more defensible than raw volume alone.

06Human review stays final

The output is a prioritization index for queue ordering, not a calibrated probability or autonomous decision.

Final takeaway

EDA changed the modeling plan: it ruled out easy shortcuts, exposed timestamp ambiguity, and focused the feature search on how transaction behavior changes as a signal approaches.
