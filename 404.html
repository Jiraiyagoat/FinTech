02 / Method

Built around the timestamp boundary, not around a leaderboard shortcut.

The signal date contains no event time. We therefore use the strictest unambiguous cutoff: only transactions strictly before 00:00 on the signal date enter the production feature set.

Baseline behavior

Transaction count, active days, amount distribution, direction mix, transaction types and history completeness.

B

Temporal structure

Last-event recency, interarrival gaps, burstiness, short-gap concentration and recent cadence shifts.

C

Signal-level validation

Transactions are never split across folds. One signal produces one feature row and one target.

D

Human-in-the-loop output

The system prioritizes review queues. It does not claim to replace an analyst or provide a calibrated probability.

Final ensemble

Independent learners, common ranking scale.

Each model’s test scores are converted to percentile ranks before weighted averaging, preventing score-scale differences from dominating the blend.

04 / Practicality

A review queue, not a black-box verdict.

The product layer is intentionally narrow: rank alerts, preserve context, and make the decision boundary auditable.

1Ingest

Signal + historical transactions.

2Score

Generate a leakage-safe relative risk index.

3Prioritize

Move higher-risk signals up the analyst queue.

4Review

Human analyst inspects transaction context and decides.
